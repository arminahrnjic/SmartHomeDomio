# Slike — Smart Curtain Robot

Ubaci ovdje finalne fotografije/CGI proizvoda kao `1.jpg`, `2.jpg`, `3.jpg`, itd. (redoslijed = redoslijed u galeriji).

Preporuke:
- Format: `.jpg` ili `.png`, idealno 1200x1200px ili veće, kvadratni ili 4:3 odnos
- Prvo (`1.jpg`) treba biti glavna/hero fotografija proizvoda

Nakon što ubaciš fotografije, javi mi (Claude Code) i ažuriraću `data/products.json` (`images` niz za `smart-curtain-robot`) da odgovara stvarnim nazivima fajlova — stranica proizvoda automatski prestaje prikazivati placeholder galeriju čim su slike prisutne.
